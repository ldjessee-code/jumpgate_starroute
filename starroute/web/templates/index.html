Jumpgate Starroute

A tool for drawing routes between real stars, for game masters and authors.

Color set for the whole tool. Building a neighborhood and drawing routes stays on Choose the stars.

Ignores a NASA download. Uses the small sample that shipped with this page. First click loads a Python engine in the browser.

NASA star and planet lists

Load NASA’s planet list and star list. Use a matching pair from the same day. You can keep the files already on this computer, or choose your own. Sol is added later, because NASA does not include it.

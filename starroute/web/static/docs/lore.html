Jumpgate Starroute

Lore vault (static wiki)

Setting text is ordinary Markdown. The viewer follows the map pack you last picked (crowded / sparse / lonely humans). There is no Wiki.js, Obsidian, or database.

Open the lore viewer →

Layout

setting/crowded/              shipped Turquenish neighborhood
setting/sparse/               thin-grid variant
setting/lonely_humans/        human-only expansion
setting/custom/{pack}/        your committed pages (kept separate)
setting/source/               tabletop notes (not mixed into packs)

starroute/web/static/docs/lore/   what Pages serves
  pages/…                     copies of the vault
  marked.min.js               MIT Markdown renderer (vendored)

Add or edit a page

The viewer has Add a page and Edit page. That editor is a small split Markdown box (textarea + live preview) using the already-vendored MIT marked parser — no extra app, no accounts.

  • Shipped pages are not overwritten. Edit saves a copy into this browser.
  • Your pages stay in this browser (localStorage) until you Export JSON, or until a maintainer commits files under setting/custom/{pack}/.
  • Load files imports .md or an exported JSON pack into the current map pack, still separate from shipped lore.

A richer MIT editor such as EasyMDE would also be license-safe. We kept the built-in split view so Pages does not need another library.

Commit a page into the repo

  1. Put Markdown in setting/custom/crowded/ (or sparse / lonely_humans) — not next to the shipped Turquenish files.
  2. Optional front matter: 
    ---
title: Your topic
order: 40
pack: crowded
---
  3. python -m starroute build-lore
  4. Commit the new .md and starroute/web/static/docs/lore/.

Try it locally

cd starroute/web/static
python -m http.server 8765

Then open http://127.0.0.1:8765/docs/lore/ (or .../docs/lore/index.html). Raw file:// is unreliable because the viewer fetches Markdown.

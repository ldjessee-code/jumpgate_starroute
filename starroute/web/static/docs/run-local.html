Jumpgate Starroute

Run locally

Two different things get called “local.” The first is enough for most people. The second is extra power.

  1. Just the webpage — open the static files. No Python.
  2. The Python app — optional. Turns on the gray tabs and catalog tools. See what that adds.

1. Easiest: open the webpage from files you already have

You need a copy of starroute/web/static/ (a git clone, a zip, a USB stick, a NAS share, or a cloud folder mounted as a drive: OneDrive, Dropbox, iCloud, and similar).

You need a recent desktop browser with WebGL: Chrome, Edge, Firefox, or Safari. Phones can look around; a laptop or Chromebook is more comfortable for GM use. No extra browser add-ons.

Try this first: in File Explorer (Windows), Finder (macOS), or your file manager, open the static folder and drag app.html (or index.html) onto a browser window.

If the map stays empty or lore pages fail to load, the browser blocked local file fetches. That is common in Chrome and Edge. Then use a tiny server (below) or the hosted site.

If drag-and-drop is blocked

Point any small static server at that same folder — still no Python app, just a way to serve files over http://:

cd starroute/web/static
python -m http.server 8765
# Windows without python on PATH: py -3 -m http.server 8765
# then open http://127.0.0.1:8765/

Node users can run npx --yes serve -l 8765 starroute/web/static. The files can still live on a USB drive or mounted cloud folder; the server only needs to see that path.

2. Optional: the Python backend

Only if you want the parked tabs and command-line rebuilds. Feature list compared to Pages.

python3 -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m starroute serve

Open http://127.0.0.1:8050 (the app’s port). That is FastAPI, not the tiny static server above.

Libraries that pip installs (from requirements.txt): pandas, numpy, scipy, networkx, FastAPI, uvicorn, python-multipart, Jinja2. Python 3.9 or newer (3.11+ preferred). No extra OS packages beyond that for the default path. NASA CSVs in data/raw/ are optional; without them, pack rebuilds use the committed sample catalog.

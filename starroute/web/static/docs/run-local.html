Run the webpage locally

The map loads preset JSON with normal web fetches. Opening app.html as a raw file:// URL often fails in Chromium browsers because local file fetches are restricted. Use a tiny static file server, or use the hosted GitHub Pages site.

What you need

  • A copy of the repo (or at least starroute/web/static/).
  • Any static file server pointed at that folder.
  • A current desktop browser with WebGL (Chrome, Edge, Firefox, or Safari).

Windows

In PowerShell or Command Prompt, from the repo root:

cd starroute\web\static
python -m http.server 8765

Then open http://127.0.0.1:8765/ or http://127.0.0.1:8765/app.html.

If python is missing, install Python 3 from python.org and ensure “Add to PATH” is checked, or use:

py -3 -m http.server 8765

Alternative with Node.js installed:

npx --yes serve -l 8765 starroute/web/static

macOS

cd starroute/web/static
python3 -m http.server 8765

Open http://127.0.0.1:8765/. Python 3 ships with recent macOS; if python3 is missing, install via python.org or Homebrew.

npx --yes serve -l 8765 starroute/web/static

Linux

cd starroute/web/static
python3 -m http.server 8765

Or:

npx --yes serve -l 8765 starroute/web/static
# or: php -S 127.0.0.1:8765 -t starroute/web/static
# or: ruby -run -ehttpd starroute/web/static -p8765

The map is a WebGL-style viewer. Phones work for a look-around; a desktop or Chromebook is more comfortable for GM use. Android is fine as a client of GitHub Pages; it is a poor place to host the builder.

Optional: Python builder on your machine

Only needed to regenerate packs, not to view them:

python3 -m venv .venv
# Windows: .venv\Scripts\activate
# Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m starroute build-presets

Quick checks

  • /presets/index.json returns JSON listing crowded / sparse / lonely_humans.
  • /app.html shows a preset control in the map UI.
  • /docs/lore/ lists stub setting pages and renders Markdown.
  • Browser developer tools → Network shows the chosen presets/<id>/map.json loading with status 200.

# Sparse — the thin grid

Crowded-pack space is a street grid. This is a highway system.

**What changed (in-setting):**

- The smallest hosts never got rings — or they lost them when usage crashed.
- Surviving jumps are longer. A “short” hop here would have been a medium
  hop on the crowded map.
- Human wedges are still Turquenish / Mardat / Hegemony / Faithful /
  independents, but each claimed star is a bigger deal. There is less
  filler.
- Alien pockets sit on the habitats they must have (giants, high-dec skies,
  gardens) and do not infill the gaps.

**What did not change:**

- Faetheren still punish quiet. A thin grid has fewer redundant paths, so
  neglect is existential.
- The war’s leftover laws still gum the remaining checkpoints.
- Mixed crews still work because nobody has enough hulls.

Play it as the same decade as the crowded pack, a few years further into
the recovery — or as a region that was always the Empire’s outer lattice.
The catalog is the same 60 ly bubble; the map simply refuses the tiniest
stars.

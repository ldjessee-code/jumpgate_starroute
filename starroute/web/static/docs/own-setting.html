Jumpgate Starroute

Use the map with your own setting

The three map packs keep their stars and jump routes. You can replace the story pages without rebuilding the sky.

Blank templates

  • crowded.json — dense neighborhood
  • sparse.json — thin grid
  • lonely_humans.json — humans only
  1. Download the template that matches the pack you play.
  2. Open it in any text editor. Change the Markdown inside pages. Keep pack and the id prefix (custom/crowded/…).
  3. On Lore, pick that map pack, then Load files and choose your JSON (or separate .md files).
  4. Your pages show under Your pages. Shipped Turquenish text stays; it is not overwritten.

Load is per browser. Export JSON if you want a backup, or commit Markdown under setting/custom/{pack}/ and run python -m starroute build-lore.

What does not change

  • The 3D map still uses the pack’s stars, routes, and painted culture labels (unless you self-host and rebuild).
  • Legend colors stay until you click a swatch on the map.
  • Lore can display those hues on culture names (Match map colors). That switch is display-only.

Context help

Yes — this is only HTML, CSS, and JavaScript. No extra library.

  1. On the map, click the round ? just left of Terms & Help docs (or press ?). Settings is the gear above those.
  2. Click a control, heading, the 3D map, the legend, a lore panel, or a settings field.
  3. A card pops up next to the click. Gold dashed outlines show what has a write-up.
  4. Press Esc or click ? again to leave help mode.

Terms & Help docs opens the full glossary. There are no extra ? marks beside each label.

What can be tagged

Anything with data-help="termId" or data-term="termId". The text lives in js/glossary.js (MIT, in this repo).

  • Map pack, path From/To, culture highlight, the plot, the legend, Settings, Generate new map
  • Gray self-host tabs (Who lives where, Choose the stars) — cards link to what self-hosting adds
  • Lore pack dropdown, page list, article, Add/Edit, Load/Export, Match map colors
  • Home and docs sections

If nothing happens

Hard-refresh (Ctrl+F5). Help mode only talks about outlined items. Clicking empty page chrome shows a “nothing tagged here” card instead of failing silently.

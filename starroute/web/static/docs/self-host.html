What self-hosting adds

The public site is a finished demo: three map packs, lore, and docs. Nothing on that host runs Python. Self-hosting is optional. Start with just opening the webpage if you only want to look around.

On GitHub Pages (already there)

  • Open the map, switch Crowded / Sparse / Lonely humans
  • Read lore for that pack; add/edit your pages in this browser
  • Load a blank setting template
  • Context help, culture glow, save/open a map JSON

How to put a copy on the public internet after that: Deploy.

Python extras (only this path)

Python 3.9 or newer (3.11+ is nicer). A virtualenv, then pip install -r requirements.txt:

pandas, numpy, scipy, networkx
fastapi, uvicorn, python-multipart, jinja2

No browser plugins. The map still uses a recent Chrome, Edge, Firefox, or Safari with WebGL, same as the static site.

Same repo, two jobs

Static host — this site. Ship starroute/web/static/ (map UI + preset JSON). Visitors only need a browser.

Builder — optional Python on a maintainer machine to regenerate packs after you change knobs or catalogs. Pages does not run that stack.

MIT licensed. Docs describe what to host and run, not click-paths through vendor dashboards that change often.

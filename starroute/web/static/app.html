Campaign

Name the box this map lives in. Chronos and Worldstack IDs are stored for later; those peers are not pulling live data from this desk yet.

Reality

Set this first. It is provenance (how much you may invent), not jump length. It does not redraw the map until you generate.

  • 0 Catalog — NASA only
  • 1 Gap-fill — extra moons/bodies, not extra stars or roads
  • 2 Soft fiction — overrides on existing hosts
  • 3 Setting-scale — invented routes/factions among catalog stars
  • 4 Procedural — new hosts and moved stars

Reality 1 invents stub moons when a system has a premise need. It does not close jump holes. Jump holes are on Generate map (raise the hop past the hole, then generate).

Jump gaps

            
A gap is a pair farther than Longest single jump. First use an existing star that can be the extra hop (low score / few planets / off-grid). If none, place a minimum-mass star (Smallest stars on the grid, default 0.25 M☉) on the line between them.

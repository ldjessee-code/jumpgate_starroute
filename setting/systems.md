# Systems

The default origin is **Sol**. Distances are light-years. The shipped sample
catalog is a **60 ly** bubble: nearby hosts that already appear in NASA’s
exoplanet tables.

Useful nearby names you will see on the map (spellings follow the catalog):

- `alf Cen A` / `alf Cen B` — the nearest other Sun-like pair
- `tau Cet`, `eps Eri`, `eps Ind A` — classic “almost like home” neighbors
- `61 Vir`, `HD 219134`, `55 Cnc` — busier catalogs, more planets on file

A system on the map is a **star plus whatever planets the catalog recorded**.
Nearby stars with no confirmed planets are missing unless you add them by
hand later.

## Jump geography

Routes grow outward from a root (usually Sol). Short hops always connect;
medium and long hops get pickier about world score. The three map packs
change **mass cuts** and **max jump** so the largest connected piece stays
in the “local neighborhood” range (about 30–100 systems in the shipped
builds).

Treat unlinked dots as known stars the jump grid has not claimed yet — not
as empty void.

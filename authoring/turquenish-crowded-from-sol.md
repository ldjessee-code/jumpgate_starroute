# Turquenish crowded — notes from Sol outward

Hold this sheet. It lists the current 90-star Crowded snapshot, and that snapshot is not the map to keep. The next generation must fit every human-held system in the Turquenish source of truth and as many other catalog systems as the jump rules allow. Some further non-human factions may be off the map. Fill nothing here until that new map exists. Setting prose stays in `F:\Dropbox\Projects\Turquenish`.

Working sheet for the **Crowded** pack (16 ly jumps, about 90 linked stars).
This file is not a lore page. `setting/**/*.md` is what the wiki publishes.

Walk the hops in order. Within a hop, nearer to Sol comes first.
“In from” is one shortest jump-path from Sol (fewest gates, not fewest light-years).
A star can have other roads. Those are listed too.

Fill only what you want to decide. Blank stays blank.

- **Setting name** — what people call it, if the catalog name is not the name
- **Line** — one sentence a table hears first
- **Port** — none, minor, standard, major
- **Fuel** — no, or yes and a price in whatever unit this setting uses
- **Buys / sells** — a few words
- **Tolls** — on the roads you care about. Leave the rest for later.

The **Sparse** pack is the same war on a different graph. Finish this walk before that one.

# Static preview

Open `index.html` or `../starroute/web/static/app.html` in a browser.

Prefer the GitHub Pages site or a local static server
(`python -m http.server` in `starroute/web/static`). Raw `file://` often
blocks fetches.

The crowded pack boots from `default-map.js`; the toolbar switches among
`crowded`, `sparse`, and `lonely_humans`. Click **?** then a control for
context help. Python is only required to regenerate packs or the lore index.
